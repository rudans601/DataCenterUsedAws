# EKS 100회 평가 결과

2026년 11월 22일(KST) EKS 실습에서 18종을 100회 관측했다. 모델은 `gpt-5.6-terra`, 런북은 3.0, 프롬프트는 `rag-decision-v3.0`, 워크로드 채점은 `workload-v3.0`을 사용했다. 계획 시드는 `979328707`이다.

95회차는 부하 발생기 연결 오류 후 같은 회차로 다시 실행했다. 2회차는 당시 앱 재시도로 종료됐으며, 11월 23일에 원래 관측 자료만 모델에 전달해 판정을 추가했다. 전체 모델 판정 100건에는 이 사후 판정 1건이 포함된다.

기존 워크로드 상황 14종은 EKS에서 재현했다. API 서버 응답 실패·스케줄러 배치 중단·컨트롤러 반영 지연·etcd 저장 공간 한도 초과 4종은 실제 EKS 앱 HTTP와 시드 기반 운영 기록을 함께 평가했다.
