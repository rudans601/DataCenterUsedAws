# 장애 사례 (예시): 설정 플래그 오타로 인한 반복 재시작

## 상황
- 실습 중 api 서비스 새 버전을 배포한 직후 새 Pod 1개가 CrashLoopBackOff에 빠졌다.
- maxUnavailable=0 설정이라 이전 Pod 2개가 계속 트래픽을 처리해서 사용자 영향은 없었다.

## 원인
- 새 리비전의 실행 인자에 존재하지 않는 플래그(오타)가 들어가 애플리케이션이 `unknown flag` 에러를 내고 바로 종료됐다.

## 근거
- 재시작 전 컨테이너 로그: `Error: unknown flag`
- 배포 이력: 직전 리비전 대비 실행 인자 1개 추가

## 조치
- 직전 리비전으로 롤백 후 매니페스트의 플래그 이름을 고쳐 다시 배포했다.

## 교훈
- 배포 전 `--help` 출력과 플래그 이름을 대조하는 검사를 CI에 추가한다.
