# 요청 시계열이 없을 때
버전 2.0 · Prometheus scrape / 요청 지표 누락

## 증거 수집
Prometheus 응답, 대상 수집 상태, 마지막 표본 시각과 현재 요청 발생 여부를 확인한다. rps=0과 값 없음은 다르다. 정상 주소로 독립 HTTP 요청을 보내 응답 코드·시간을 측정한다. 새 Pod가 배포된 직후에는 수집 간격과 rate 구간도 확인한다.

## 처리
직접 요청이 성공하고 첫 수집 구간만 비면 관찰하고 다시 측정한다. 여러 수집 구간에서 공백이 이어지면 수집 설정·레이블·대상을 모니터링 담당자에게 인계한다. 다른 근거까지 부족하면 서비스 장애 판정을 보류한다. 지표 누락을 추정 수치로 채우거나 정상인 Pod를 재시작하지 않는다.

## 종료 기준
새 요청이 발생하는 동안 요청량, 5xx, 지연 시계열에 최신 표본이 다시 나타나는지 확인한다. 직접 호출 성공만으로 모니터링 복구를 선언할 수 없다.
